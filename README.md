# RetroPi

Web app (instalable en el móvil) para consultar mi colección de videojuegos.

- **Fuente de datos:** una hoja de Google Sheets, leída a través de un Apps Script publicado como aplicación web (solo lectura).
- **Privacidad:** este repositorio solo contiene el código. La URL del Apps Script y la clave se introducen en la app la primera vez y se guardan **solo en el dispositivo**. Sin la clave, el Apps Script responde "No autorizado".
- **Versión 1:** Mega Drive, Master System y NES · lista y estantería · ficha · búsqueda global · Finanzas. Solo lectura.

## Instalar en el móvil
1. Abre la web de GitHub Pages de este repositorio en el móvil.
2. iPhone (Safari): Compartir → *Añadir a pantalla de inicio*. Android (Chrome): menú ⋮ → *Instalar aplicación*.
3. La primera vez, pega la URL `/exec` del Apps Script y tu clave.
